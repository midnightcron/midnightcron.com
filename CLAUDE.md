# Project guide for Claude Code

Project-scoped guidance. Travels with the repo.

## What this is

Personal site and project hub for Robin Worreby. FastAPI + Jinja2 +
Pico.css. Public URL: https://midnightcron.com. Deployed on a Raspberry Pi 4
behind a Cloudflare Tunnel. Repo: https://github.com/midnightcron/midnightcron.com.

Sibling projects on the same Pi: `kicker` (foosball ELO), `badi_attendance`
(pool occupancy), `autoverlad` (Swiss car-train wait times), `training_coach`
(training-load reports). The same stack pattern applies across all of them.

## Commands cheatsheet

Local dev (any OS):

    uv sync                                    # install deps
    uv run uvicorn app.main:app --reload       # start the app
    uv run pytest -q                           # run tests
    uv run ruff check .                        # lint

If `uv` is not on PATH (Windows after `pip install uv`), prefix with
`python -m uv`.

Deploy to the Pi:

    tailscale ssh pi@rpi 'cd /home/pi/coding/midnightcron.com && ./scripts/deploy.sh'

Pi facts (same as kicker):

- Tailnet hostname: `rpi`
- Linux user: `pi`
- Repo path: `/home/pi/coding/midnightcron.com`

## Conventions

- **Branch naming**: `feat/<short-name>`, `fix/<short-name>`, `chore/<...>`.
  Tiny one-line fixes can go straight to `main`.
- **Commits**: imperative subject, no Co-Authored-By line, no Claude mention.
- **Style**: no em dashes in any prose, code, or commit messages. Use commas,
  colons, or parentheses instead.
- **Comments**: minimal. Only write one when the WHY is non-obvious.
- **No DB**: this app is static content rendered server-side. Do not add
  SQLite, Postgres, or any persistence without first questioning whether
  the content belongs in `app/projects.py` or a flat Jinja partial instead.

## Architecture notes

- `app/main.py`: four routes (`/`, `/about`, `/projects/<slug>`, `/health`).
  Keep it small. If a page needs logic, write a helper, not a router split.
- `app/projects.py`: single source of truth for project metadata. Adding a
  project is one dict append, no template changes.
- `app/templating.py`: shared Jinja env + `static_version` cache-buster
  global. Identical pattern to kicker; see kicker's CLAUDE.md for the
  original Cloudflare cache incident.
- `app/templates/`: `base.html` is the only layout. `partials/project_card.html`
  is the only partial. Resist subdividing further until there is a second
  card type.
- `app/static/css/site.css`: custom dark + monospace overlay on top of
  Pico.css 2. CSS variables override Pico's tokens. Keep the file in one
  piece; do not split into per-component files until it crosses ~400 lines.

## Multi-device workflow

Start of session on any device:

    git fetch && git pull --ff-only

End of session, before switching devices:

    git push

The `.env` is gitignored. Each device needs its own (only `TUNNEL_TOKEN` for
the Pi, blank everywhere else).

## Deploy procedure

1. Push to `main`.
2. `tailscale ssh pi@rpi 'cd /home/pi/coding/midnightcron.com && ./scripts/deploy.sh'`.
3. Live at https://midnightcron.com.

## Things you do not do without asking

- Bump a major dependency
- Add a database, a queue, a background worker
- Switch CSS frameworks
- Force-push to `main`
- Add Co-Authored-By or "Generated by Claude" footers to commits

## Local visual preview (Claude Code preview tool)

The `mcp__Claude_Preview__*` tools read `<workspace>/.claude/launch.json`
(the workspace dir is the parent of the repo, not the repo itself).

On a new machine, add a `midnightcron-com` entry to
`<workspace>/.claude/launch.json`:

```json
{
  "name": "midnightcron-com",
  "cwd": "midnightcron.com",
  "runtimeExecutable": "python",
  "runtimeArgs": ["-m", "uv", "run", "uvicorn", "app.main:app",
                  "--host", "127.0.0.1", "--port", "8766"],
  "port": 8766
}
```

Adjust `runtimeExecutable` if `uv` is on PATH (`uv` directly instead of
`python -m uv`). Pick a free port; kicker uses 8765.
